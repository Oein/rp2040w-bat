# KiCad 프로젝트 — RP2040W-BAT

**열리는 KiCad 프로젝트**입니다. `generate_kicad.py`가 아래를 생성합니다.

| 파일 | 내용 |
|---|---|
| `rp2040w-bat.kicad_sch` | 전체 보드 스키매틱 (45개 부품, 심볼 임베드, 글로벌라벨 결선) |
| `rp2040w-bat.kicad_pro` | 프로젝트 파일 |
| `rp2040w_bat.kicad_sym` | 편집용 심볼 라이브러리 |
| `sym-lib-table` | 프로젝트 심볼 라이브러리 등록 |

KiCad **7/8/9** 에서 열립니다 (파일 포맷 `20230121`).

## 여는 법
1. KiCad → `Open Project` → `rp2040w-bat.kicad_pro`.
2. Schematic Editor(Eeschema)로 `rp2040w-bat.kicad_sch` 열기.

## 어떻게 만들었나 (블라인드 생성 신뢰성)
- **모든 심볼을 직접 정의** → 핀 좌표를 정확히 알고 라벨을 그 위에 정확히 놓음.
- **넷 연결 = 글로벌 라벨(이름 기반)**. 같은 이름끼리 자동 연결 → 배선 좌표 의존 최소.
  (예: `GND` 33핀, `3V3` 18핀, `VSYS` 6핀이 이름으로 묶임)
- 자동 검증 통과: **괄호/따옴표 균형 OK, 좌표 충돌(오연결) 0건, 핀↔라벨 좌표 일치 확인.**

## ✅ 검증된 것 / ⚠️ 직접 확인할 것

**제가 확인한 것**
- S-expression 문법 유효(파서 균형), 45 심볼 정의 = 45 배치.
- 서로 다른 넷이 같은 좌표에 겹쳐 생기는 **오연결 0건**.
- 핀 끝점과 글로벌 라벨 좌표 **정확히 일치**(전기적 연결 성립).
- 넷 팬아웃이 `../hardware/netlist.md`와 일치.

**여신 뒤 KiCad에서 반드시 확인(저는 EDA를 띄워 렌더 검증 불가)**
- ⚠️ **풋프린트**: `Footprint` 필드는 KiCad 표준 라이브러리 경로 *추정값*. CvPcb/심볼속성에서 실제 부품과 대조.
- ⚠️ **복잡 IC 핀 '번호'**: RP2040/BQ25180/RT6150/CYW43439/USB-C 는 핀 **기능명**을 번호로 사용.
  데이터시트로 **풋프린트 패드 번호 ↔ 기능** 매핑을 채워야 PCB 넷이 맞음.
  (플래시 U2·수동소자·커넥터 J2는 실제 핀번호 사용)
- ⚠️ **ERC**: 모든 핀을 `passive`로 둠(파워 드라이버 ERC 회피). GPIO 단일핀 넷(GP0~GP19 등)은
  캐슬레이션/매트릭스로 나가는 정상 상태 → "unconnected"로 떠도 의도된 것.
- ⚠️ **무선 RF**: CYW43439·안테나는 Pico W 거버 복제가 정석(`../docs/03`). 이 심볼은 결선용 자리표시.

## 재생성
```bash
python3 generate_kicad.py
```
`comps` 리스트(부품·핀·넷)를 고쳐 회로를 바꾸고 다시 생성하면 됩니다.

## EasyEDA로 가져가기
EasyEDA **Pro** 는 `File → Import → KiCad` 로 이 프로젝트를 가져올 수 있습니다.
(또는 `../hardware/bom.csv` + `../hardware/netlist.md` 로 EasyEDA에서 직접 작도 — `../easyeda/README.md`)

> 이 프로젝트는 **검증된 시작점**입니다. 풋프린트·IC 핀번호·RF만 확정하면 PCB로 진행 가능합니다.
