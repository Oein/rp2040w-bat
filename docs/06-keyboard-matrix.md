# 06. 키보드 본체 — 매트릭스 · 다이오드 · 웨이크

> 핀맵 제약(docs/01) 안에서 행/열 GPIO를 배정한다. 외부 노출 GPIO만 사용.
> (이 저장소는 "메인보드 IC" 중심이므로 매트릭스는 GPIO 배정·규칙 위주.)

## 1. 사용 가능한 GPIO 예산

- 외부 노출: **GPIO0~22, 26~28 = 26개**.
- 예약(전원/통신용으로 빼두기):
  - I2C(BQ25180): 예 GPIO20(SDA)/GPIO21(SCL)
  - BQ25180 /INT: 예 GPIO22
  - (선택) VBUS 보조 ADC: GPIO26~28 중 1
  - SWD는 전용 핀(GPIO 아님)
- 남는 GPIO로 매트릭스 구성.

## 2. 매트릭스 배정 예 (풀사이즈가 아니면 더 여유)

| 용도 | GPIO |
|---|---|
| 행(ROW) 출력 | GPIO0~7 (8행) |
| 열(COL) 입력 | GPIO8~19 (12열) |
| → 8×12 = 96키 | (60% 키보드 이상 커버) |
| I2C/INT/ADC | GPIO20·21·22·(26) |
| 여유 | GPIO27·28 |

> 실제 키 수에 맞춰 행/열 수 조정. PIO를 쓰면 스캔 효율↑.

## 3. 다이오드 (고스팅 방지)

- **키마다 1N4148W(또는 SOD-123) 1개**, **방향 통일**.
- 표준: **COL→ROW** 방향(또는 ROW→COL) 중 하나로 전부 통일. 펌웨어 스캔 방향과 일치.
- 권장: 각 스위치에서 ROW로 들어가는 쪽에 캐소드/애노드 일관 배치.

## 4. 웨이크 인터럽트 라인 (슬립 복귀)

- 슬립(dormant) 중 **임의 키 입력으로 깨어나야** 함(docs/05 §4).
- 방법: 슬립 진입 시 **모든 ROW를 active로 구동**하고 **하나의 COL(또는 OR된 라인)을 인터럽트 소스**로 설정.
  - 또는 전용 "웨이크 라인" 1개를 모든 키의 공통 노드에 다이오드로 OR.
- 깨어난 뒤 정상 스캔으로 어떤 키였는지 판별.

## 5. 표시 LED (선택)

- 무선/유선 모드, 충전 상태 표시.
- 온보드 상태 LED는 **WL_GPIO0**(Pico W LED 위치) 재사용 가능 — 펌웨어 제어.
- 충전 표시는 BQ25180 /INT 상태를 펌웨어로 읽어 별도 LED 구동(여분 GPIO).

## 6. 배치 주의 (레이아웃)

- 매트릭스/스위치는 보드 본체에. 전원부 확장영역(USB측)과 분리.
- 스위치 풋프린트는 별도(이 IC 보드는 컨트롤러 모듈 형태일 수 있음) — 키 PCB와 커넥터/캐슬레이션으로 연결하는 구성도 가능.
