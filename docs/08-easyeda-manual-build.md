# 08. EasyEDA Pro 수동 작업 가이드 — RP2040W-BAT 배터리/충전부 추가

대상: 사용자가 EasyEDA Pro에서 만든 **RP2040W-BAT 보드**(Alta alpha 컨트롤러 재사용).
이미 있는 것: **U1 RP2040 / U7 W25Q128 / U8 CH340C(UART) / U4·U9 ME6211(LDO) / USB-C(USB1·USB3) / X1 크리스탈** 등.
목표: 현재 "USB 5V → LDO → 3V3" 전원부 앞단에 **배터리+충전+파워패스+벅부스트**를 삽입.

> 모든 부품은 EasyEDA Pro 좌측 **라이브러리 검색창에 LCSC 번호 입력 → Place**. (검증된 심볼+풋프린트)

---

## 0. 현재 전원 구조 파악 (먼저 회로에서 확인)
- **USB VBUS(5V)** 네트: USB-C(USB1) VBUS 핀에서 나오는 5V.
- **3V3** 네트: U4/U9 ME6211 출력 → RP2040·플래시 전원.
- **GND**.
- 이 3개 네트 이름을 회로에서 클릭해 확인해두세요(아래에서 연결 기준점).

## 1. 추가할 부품 (LCSC 검색 → 배치)
| 지정자(새로) | 부품 | LCSC | 용도 |
|---|---|---|---|
| U10 | **BQ25180** | **C2682744** | 충전+파워패스+ship+버튼+I2C |
| U11 | **RT6150B** | **C2830944** | VSYS→3V3 벅부스트 |
| J10 | **JST PH 2P** | **C173752** | 1S 리포 배터리 |
| L10 | **2.2µH 인덕터** | **C167219** | 벅부스트 |
| RT10 | **NTC 10k** | C13564 | 배터리 온도(TS) |
| R30,R31 | **5.1k** | C25905 | USB-C CC1/CC2 (이미 있으면 생략) |
| R32,R33 | **4.7k** | C25900 | I2C SDA/SCL 풀업 |
| R34 | **100k** | C25741 | BQ INT 풀업 |
| R35 | **100k** | C25741 | 벅부스트 EN→VSYS |
| R36 | **100k** | C25741 | 전원버튼→VSYS |
| C70 | 1µF | C15849 | BQ IN |
| C71 | 1µF | C15849 | BQ SYS |
| C72 | 1µF | C15849 | BQ BAT |
| C73 | 10µF | C15850 | 벅부스트 IN |
| C74 | 22µF | C45783 | 벅부스트 OUT |
| SW10 | 택트 | C318884 | 전원 버튼(3초 ON) |

## 2. 전원 프론트엔드 재배선 (핵심)
현재: `USB VBUS → (LDO U4/U9) → 3V3`
변경: `USB VBUS → U10(BQ25180) IN → SYS → VSYS → U11(RT6150) → 3V3`

순서대로:
1. **USB VBUS 네트**를 **U10(BQ25180) IN** 핀에 연결. (USB 5V는 더이상 LDO로 직행하지 않음)
2. **U10 SYS** → 새 네트라벨 **`VSYS`** 부여 → **U11(RT6150) VIN** 에 연결.
3. **U11(RT6150) VOUT** → 기존 **`3V3`** 네트에 연결. (RP2040·플래시가 여기서 전원 받음)
4. **기존 LDO U4/U9 처리**: 배터리 전용이면 **제거/미배치(DNP)**.
   - (선택) "USB 연결 시 LDO, 배터리 시 벅부스트" 같은 이중화는 복잡 → 권장 안 함. 벅부스트 단일화.
5. **U10 BAT** → **J10(JST) 1번** = 네트 **`VBAT`**, J10 2번 = GND.
6. **L10(2.2µH)**: RT6150 SW1↔SW2 핀 사이(데이터시트 권장 배치).

## 3. USB-C 입력 점검 (이미 USB-C면 확인만)
- **CC1·CC2 각각 5.1k → GND** (R30/R31). **하나로 묶지 말 것.** 이미 있으면 OK.
- **D+ 양 페어(A6·B6) 묶기 / D- 양 페어(A7·B7) 묶기.**
- USB D+/D-는 기존대로 RP2040 USB(직렬 27Ω)로. (CH340 U8과의 분기는 기존 회로 유지)
- **USB VBUS핀을 VSYS/3V3에 직결 금지** — 반드시 BQ25180 경유(역류 방지).

## 4. 제어/보조 결선
| 신호 | 연결 |
|---|---|
| BQ SDA/SCL | RP2040 여유 GPIO 2개(예 GP20/GP21) + R32/R33 4.7k→3V3 |
| BQ INT | RP2040 GPIO(예 GP22) + R34 100k→3V3 |
| BQ CE/버튼 | SW10 → GND, R36 100k→VSYS |
| RT6150 EN | RP2040 3V3_EN 상당 네트 또는 R35 100k→VSYS (기본 ON) |
| RT6150 PS | (Pico W는 WL_GPIO1) 여기선 GND 또는 GPIO |
| BQ TS | RT10 NTC 10k→GND (미사용 시 데이터시트 고정분압) |

> 정확한 BQ25180/RT6150 핀 이름은 EasyEDA가 배치한 **심볼의 실제 핀**을 기준으로(LCSC 심볼).
> 기능↔핀 매핑은 `../hardware/netlist.md` 와 데이터시트로 대조.

## 5. 배선 팁 (EasyEDA Pro)
- 전원/접지/공유 신호는 **네트라벨(단축키 N) 또는 Netflag** 로 이름 붙여 연결 — 멀어도 이름으로 묶임.
  - 새 네트: `VSYS`, `VBAT`. 기존: `3V3`, `GND`, USB `VBUS`.
- 충전 IC 주변 캡(C70~C74)은 각 핀 가까이.

## 6. 마무리
1. **Design → Check DRC/ERC** (Schematic) 통과.
2. **Convert Schematic to PCB** → 부품 임포트.
3. PCB 외곽/배치는 `../docs/07-layout-mechanical.md`:
   - **폭·핀 위치 고정, 확장은 USB-C 방향으로만.** 배터리/충전부를 USB측에 모음.
4. 전원로직(유선=켜짐 / 버튼3초 / ship 종료)은 펌웨어 + BQ25180 I2C: `../docs/05-power-logic.md`.

## 참고: 왜 파일을 직접 안 고치고 가이드인가
EasyEDA Pro는 프로젝트 정본을 **암호화된 history**에 저장하고, 열 때 그걸 체크아웃합니다
(`../eda_work/README.md` 분석 참조). 그래서 `.eprj2` 평문을 외부에서 고쳐도 앱에서 덮어써질 수 있어,
**EasyEDA 안에서 직접 배치/배선하는 것이 가장 확실**합니다. 위 표/넷은 그 작업을 그대로 따라가게 만든 것.
