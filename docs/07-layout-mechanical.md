# 07. 레이아웃 · 기구 제약 — "확장은 USB/충전 방향으로만"

> **사용자 요구**: RP2040W 보드에서 **충전 포트 쪽으로는 회로가 더 길어져도 되지만,
> 다른 방향으로는 절대 길어지면 안 된다.**
> → Pico W 외곽(폭·핀 위치)을 고정하고, **신규 전원부는 USB-C가 있던 짧은 변 바깥으로만** 확장.

## 1. 외곽 치수 (Pico W 기준 고정)

| 항목 | 값 | 제약 |
|---|---|---|
| 폭(W) | **21.0 mm** | **변경 금지** (좌/우 캐슬레이션 위치 유지) |
| 길이(L) | 51.0 mm + **ΔL(확장)** | **USB측으로만** ΔL 추가 허용 |
| 두께 | 1.0 mm | 권장 유지 |
| 핀 피치 | 2.54 mm (0.1") | 40핀 캐슬레이션 |
| 코너 | R 라운드 | Pico W 동일 |

## 2. 좌표계 / 확장 방향

```
        ┌──────── 21.0mm (고정 폭) ────────┐
        │   [확장영역 ΔL: USB-C·BQ25180·   │   ← USB-C/충전 방향 = 확장 OK
        │    배터리 JST·인덕터·보호소자]    │
        ╞══════════════════════════════════╡  ← 원래 Pico W 상단(USB 위치)
   핀1 ─┤  [RP2040]   [CYW43439]            ├─ 핀40
        │                                   │
   좌측 │   ← 변경 금지 (폭/핀 위치 동일) → │ 우측
  캐슬   │      [플래시] [크리스탈]          │  캐슬
        │                                   │
   핀20 ┤   ████ 안테나/RF (키프아웃 유지) ████ ├─ 핀21
        └──────────────────────────────────┘  ← 하단: 변경 금지
                  ▲ RF 영역은 절대 침범 금지
```

- **확장영역(상단, USB측)**: USB-C 커넥터, BQ25180, 배터리 커넥터(JST), 입력 보호(TVS/ESD),
  벅부스트 인덕터·캡, VBUS 분압 등 **신규 전원 부품 전부**를 여기로.
- **본체영역(기존 Pico W 풋프린트)**: RP2040·플래시·크리스탈·CYW43439·안테나는 위치 유지.
- **좌/우/하단 3면**: 폭·핀·외곽 **불변** → 기존 Pico W 소켓/캐리어에 드롭인.

## 3. 핀 위치 1:1 고정

- 40핀 캐슬레이션 X/Y 좌표·번호를 **Pico W 풋프린트와 1:1** (docs/01).
- ΔL 확장은 **1번/40번 핀이 있는 USB측 변 너머**로만. 핀 줄(좌/우 변)은 길이 유지.
- VSYS(39)·VBUS(40)·3V3(36)·GND 위치 동일.

## 4. RF 영역 보호

- CYW43439 안테나·매칭·키프아웃은 **Pico W 거버 그대로 복제**(docs/03).
- 확장영역(USB측)은 안테나(보통 하단/측면)와 멀어 **RF 간섭 최소** — 이 방향 확장이 RF에 유리.
- 전원부 스위칭(벅부스트·충전 IC)을 안테나에서 떨어뜨림 → 노이즈 격리.

## 5. 스택업 / 라우팅 (PCB 단계 가이드)

- **4층 권장**: L1 신호+부품 / L2 GND / L3 전원 / L4 신호.
- USB 차동쌍(D±): USB-C(확장영역)→RP2040, 짧고 평행, 직렬 27Ω, 90Ω 차동.
- 전원부 인러시/열: BQ25180 열패드 GND 비아 다수, 충전 전류 경로 굵게.
- 확장영역 GND를 본체 GND와 넓게 연결(단, RF 그라운드 키프아웃은 유지).

## 6. 체크리스트

- [ ] 폭 21.0 mm·핀 위치 Pico W와 동일 (좌/우/하 3면 불변)
- [ ] 확장은 USB측 변으로만 (ΔL)
- [ ] 안테나/RF 키프아웃 그대로
- [ ] USB 차동쌍 짧고 평행
- [ ] BQ25180 방열·인러시
- [ ] DRC/ERC 통과 + 핀맵 최종 대조
