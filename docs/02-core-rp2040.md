# 02. RP2040 코어부 — Pico W 레퍼런스 복제

> RP2040은 내부 코드메모리가 없어 **외부 QSPI 플래시에서 부팅**한다.
> 이 블록은 Raspberry Pi Pico W 공식 회로도를 **그대로** 따른다 (BSD, 제약 없음).

## 1. 핵심 부품

| 지정 | 부품 | 값/형번 | 비고 |
|---|---|---|---|
| U1 | RP2040 | QFN-56 (7×7) | LCSC C2040 |
| U2 | QSPI NOR 플래시 | W25Q128JVSIQ (16 MB) | SO-8 / 부팅 필수. Pico는 W25Q16, 본 보드는 펌웨어 여유로 16MB 권장 |
| Y1 | 크리스탈 | 12.000 MHz | USB 타이밍 기준. 부하용량 매칭(보통 2×15 pF 내외, 데이터시트 CL 확인) |
| — | 부하 커패시터 | C_L1/C_L2 (예 15 pF) | 크리스탈 CL에서 역산 |

## 2. 전원 핀 그룹 & 디커플링 (RP2040 하드웨어 설계 가이드 준수)

| 레일 | RP2040 핀(기능) | 공급 | 디커플링 |
|---|---|---|---|
| 코어 1.1 V | DVDD | **내부 LDO**(VREG_VIN=3V3 → VREG_VOUT=1.1V) | 1µF + 100nF, VREG_VOUT |
| IO 3.3 V | IOVDD ×N | 3V3 | 각 핀당 100nF |
| USB 3.3 V | USB_VDD | 3V3 | 100nF |
| ADC 3.3 V | ADC_AVDD | 3V3(권장 페라이트/필터) | 100nF + (선택)RC |
| VREG 입력 | VREG_VIN | 3V3 | 1µF |

- **디지털/아날로그 그라운드 분리**: AGND는 단일점에서 GND와 결합(스타). ADC_AVDD는 3V3에서 페라이트비드+100nF로 분리.
- 모든 IOVDD 핀 근처에 100nF 1개씩(짧게).

## 3. QSPI 플래시 결선

| RP2040 | W25Q128 | 비고 |
|---|---|---|
| QSPI_SS_n | /CS | 풀업 불필요(RP2040 구동) |
| QSPI_SCLK | CLK | |
| QSPI_SD0 | DI (IO0) | |
| QSPI_SD1 | DO (IO1) | |
| QSPI_SD2 | /WP (IO2) | |
| QSPI_SD3 | /HOLD (IO3) | |
| 3V3 | VCC | 100nF 디커플 |
| GND | GND | |

- 라인은 짧고 길이 비슷하게. Pico 레이아웃 권장 직렬저항/배치 따름.

## 4. USB (D+/D-)

- RP2040 **USB_DP / USB_DM** → 각 **직렬 27Ω** → USB-C D+/D- 노드.
- 차동 **90Ω**, 짧고 평행, 레퍼런스 GND 인접. (상세: docs/04 USB-C)
- USB_VDD 100nF 디커플.

## 5. 부팅/디버그

| 기능 | 회로 |
|---|---|
| **BOOTSEL** | 버튼 SW_BOOT: QSPI_SS_n ↔ GND. 부팅 시 누르면 플래시 재기입(USB 매스스토리지) |
| **RUN(리셋)** | 30번 핀 RUN. 풀업(10k→3V3) + 버튼 SW_RUN→GND + 100nF. 외부 30번 핀과 공유 |
| **SWD** | SWDIO/SWCLK/GND 3핀 패드 노출(디버그용). 본 보드 하단/USB측 끝에 패드 |

## 6. 콜드부트/전원 순서

- 3V3가 안정화된 뒤 RUN 해제(또는 RUN 풀업+RC). VREG_VIN(3V3)에서 코어 1.1V 생성.
- 전원부(docs/04)에서 **VSYS→3V3 벅부스트**가 먼저 서고, 그 3V3로 RP2040이 부팅.

> 본 블록은 신규 설계 요소가 적다. **Pico W 회로도 값/배치를 그대로 베끼는 것이 정답.**
> 변경 포인트는 (a) 플래시 용량, (b) USB-C로 D± 라우팅(직렬 27Ω 유지)뿐.
