# 03. 무선부 — CYW43439 (가장 어려움 → 통째 복제)

> **RF는 이 프로젝트의 최대 난관.** 직접 그리지 말고 **Pico W 회로도+거버를 그대로 복제**한다.
> 안테나/매칭/그라운드 키프아웃을 비트 단위로 베끼는 것이 성공의 핵심.

## 1. 두 가지 선택지

| 방식 | 장점 | 단점 | 권장 |
|---|---|---|---|
| **A. CYW43439 칩 + PCB 안테나** (Pico W 방식) | Pico W와 100% 동일, BOM 저렴 | RF 레이아웃·인증 부담, 직접 튜닝 어려움 | 거버를 **그대로** 복제할 때만 |
| **B. 인증 무선 모듈** (예: u-blox NINA-W10 / Murata 1YN 등) | RF·인증 끝난 모듈, 안테나 포함 | 핀맵/공간 재배치, 비용↑ | 처음 만들면 **B 추천** |

> 본 설계 문서는 **A(Pico W 복제)** 를 기준으로 하되, 공간이 부족하면 B로 전환 가능하도록 SPI 신호를 추상화한다.

## 2. CYW43439 ↔ RP2040 SPI 결선 (Pico W 동일)

CYW43439는 RP2040과 **gSPI(공유 SPI)** 로 연결된다. Pico W는 다음 GPIO를 무선 전용으로 사용:

| 신호 | RP2040 핀 | CYW43439 | 설명 |
|---|---|---|---|
| WL_CLK | GPIO29 | SPI_CLK | (Pico에서 ADC3였던 핀) |
| WL_CS | GPIO25 | SPI_CS_n | (Pico에서 LED였던 핀) |
| WL_DAT (반이중) | GPIO24 | SPI_D / DOUT/DIN | 단선 양방향 데이터 |
| WL_ON / REG_ON | GPIO23 | WL_REG_ON | 무선칩 전원 인에이블 |
| WL_HOST_WAKE(IRQ) | GPIO24 공유 | SPI_IRQ | 인터럽트 겸용 |

- **WL_GPIO0~3** (무선칩 내부 GPIO): LED(0), SMPS PS 제어(1), VBUS 감지(2). docs/01 참조.
- 위 GPIO23/24/25/29는 **외부 40핀에 안 나옴** → 핀호환 유지됨. Pico W SDK가 이 배선을 가정.

## 3. 전원 / 디커플링

| 레일 | 연결 | 디커플 |
|---|---|---|
| CYW43439 VBAT/VDDIO | 3V3 | 100nF + 1µF (칩 데이터시트 배치) |
| WL_REG_ON | RP2040 GPIO23 (풀다운으로 기본 OFF) | |
| 32.768 kHz? | CYW43439는 내부/외부 SLOW CLK 구성 — Pico W 회로도 따름 | |

> CYW43439 정확한 핀/볼 맵·디커플 배치는 **Pico W 회로도 + CYW43439 데이터시트**를 1:1로 대조해 옮길 것.

## 4. 안테나 / RF 레이아웃 (그대로 복사)

- **PCB 인쇄 안테나 + π매칭 네트워크** 를 Pico W 거버에서 **위치·치수·키프아웃까지** 복제.
- 안테나 영역 아래·주변 **그라운드 키프아웃 유지**(채우지 말 것).
- 50Ω(또는 설계상) 임피던스 트레이스, 매칭 부품 자리 그대로.
- 이 영역은 **본 보드에서 변경 금지 구역**. 레이아웃 제약은 docs/07 참조(확장은 USB측으로만 → RF 영역 안 건드림).

## 5. 펌웨어

- Raspberry Pi Pico SDK `pico_cyw43_arch` 사용 → 배선이 Pico W와 같으면 그대로 동작.
- BLE/Wi-Fi HID: docs/05·07(키보드) 및 펌웨어 섹션 참조.

> **요약:** SPI 6선 + REG_ON + 전원 디커플 + (복제한)안테나. 새로 "설계"하지 말고 **베껴라.**
