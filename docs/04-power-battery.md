# 04. 전원부 — USB-C · 충전 IC · 파워패스 · 벅부스트 (본론)

> 본 보드의 **신규 설계 핵심.** Pico W에 없는 "단일 USB-C(데이터+충전) + 1셀 리포 + 전원 로직".
> 충전부는 **반드시 IC(BQ25180)** 로 — 리튬셀 직접 CC/CV는 발화 위험.

## 0. 전력 흐름 한눈에

```
USB-C VBUS(5V) ──► BQ25180 VIN ──┐
                                 │ (파워패스)
                  BQ25180 SYS ───┴──► VSYS(39핀) ──► RT6150 벅부스트 ──► 3V3 레일
                  BQ25180 BAT ──────► 1셀 리포(JST)        (1.8~5.5V→3.3V)
```

- USB 있으면: VIN→SYS 직접 공급 + 동시에 BAT 충전(CC/CV).
- USB 없으면: BAT→SYS 공급(파워패스 자동 전환).
- 3V3는 **항상 VSYS에서 벅부스트로** 생성 → 배터리 전압이 3.3V 위/아래 어디든 안정 출력.

---

## 1. USB-C 커넥터 (micro-USB 대체, 단일 포트)

부품: 16핀 USB 2.0 Type-C 리셉터클 (예 TYPE-C-31-M-12 / LCSC C165948).

### 1.1 필수 결선
| 신호 | USB-C 핀 | 연결 | 주의 |
|---|---|---|---|
| VBUS | A4, A9, B4, B9 (전부 묶기) | net **VBUS_USB** → BQ25180 VIN | 4핀 모두 병렬 |
| GND | A1, A12, B1, B12 (+쉴드) | GND | 쉴드는 GND(또는 1MΩ∥1nF) |
| **CC1** | A5 | **5.1kΩ → GND** (Rd) | 빠지면 VBUS 안 들어옴 |
| **CC2** | B5 | **5.1kΩ → GND** (Rd) | CC1/CC2 각각 따로! 묶지 말 것 |
| D+ | A6 **와** B6 묶기 | net **USB_DP** | 양방향 삽입 위해 양 페어 묶기 |
| D- | A7 **와** B7 묶기 | net **USB_DM** | 〃 |
| SBU1/2 | A8/B8 | NC | 미사용 |

> ⚠️ **가장 흔한 실수 3종**: ① CC 5.1kΩ ×2 누락, ② CC1·CC2를 한 저항으로 묶음(따로 해야 함),
> ③ D± 한 페어만 연결(뒤집어 꽂으면 죽음). 셋 다 피할 것.

### 1.2 데이터 (D±) → RP2040
- USB_DP → **직렬 27Ω** → RP2040 USB_DP
- USB_DM → **직렬 27Ω** → RP2040 USB_DM
- 차동 90Ω, 짧고 평행. (내 보드라 Pico의 TP2/TP3 점퍼 납땜 불필요 — 직배선)

### 1.3 보호
- VBUS_USB ↔ GND: **TVS/ESD** (예 SMF5.0A) + 입력 벌크 1µF~10µF.
- USB_DP/USB_DM ↔ GND: USB2.0용 **ESD 어레이** (예 USBLC6-2SC6) 권장.

### 1.4 VBUS(USB 연결) 감지 — 두 방법 (둘 다 둬도 됨)
- **(A) Pico W 호환**: 펌웨어가 **WL_GPIO2**(CYW43439 GPIO2)로 VBUS 상태 읽기. 추가 부품 0.
- **(B) 보조 ADC 분압**: VBUS_USB → **100kΩ → 노드 → 100kΩ → GND**, 노드 → 미사용 ADC(GPIO26~28 중 1).
  - 5V→2.5V로 분압(3.3V ADC 안전). 무선칩 꺼진 상태에서도 하드웨어로 감지 가능.

## 2. 충전 IC + 파워패스 — **BQ25180** (핵심)

TI BQ25180: **1셀 리니어 충전 + 파워패스 + ship 모드 + 푸시버튼 + I2C** 단일 칩.
→ 요구한 "유선=켜짐 / 버튼 3초=켜짐 / 소프트웨어 종료(ship)"를 한 칩으로 충족.

### 2.1 기능 결선 (핀 *기능* 기준 — 정확한 볼맵은 데이터시트 확인)
| BQ25180 신호 | 연결 | 비고 |
|---|---|---|
| **IN (VIN)** | VBUS_USB | USB 5V 입력. 1µF 입력 캡 |
| **SYS** | **VSYS(39핀)** + RT6150 VIN | 파워패스 출력. 1µF 출력 캡 |
| **BAT** | 1셀 리포 + (JST) | 충전/방전 단자. 1µF 캡 |
| **GND** | GND | 열패드 GND |
| **SCL / SDA** | RP2040 I2C (예 GPIO21/GPIO20) | 4.7kΩ 풀업→3V3. 충전상태/배터리/레지스터 |
| **/INT** | RP2040 GPIO(예 GPIO22) | 인터럽트(충전완료/결함/버튼). 풀업→3V3 |
| **CE / 버튼** | 전원 버튼 + 풀업 | 푸시버튼/이네이블 (§2.3, 데이터시트 동작 확인) |
| **TS** | NTC 10k → GND(또는 분압) | 배터리 온도. 미사용 시 데이터시트대로 고정전압 |
| **ILIM/PROG** | 저항 또는 I2C 설정 | 충전전류 설정(§2.2) |

> ⚠️ **BQ25180의 정확한 패키지(예 DSBGA-9)·볼 배치·ship/wake 핀·CE 동작·레지스터 비트**는
> TI 데이터시트(SLUSDx)로 **반드시 1:1 확정** 후 작도. 여기 표는 *기능 결선*이다.

### 2.2 충전 전류(ICHG) 설정 — 배터리 용량 확정 후
- 기준: **0.5C** 권장(예 500mAh 셀 → 250mA), 최대 1C 이하.
- BQ25180는 I2C 레지스터로 ICHG 설정(또는 핀). **셀 용량 확정 전엔 보수적으로 ~0.5C.**
- 종지전압 4.2V(표준 리포). 데이터시트 CV 설정 확인.

### 2.3 전원 로직 핵심 (자세히는 docs/05)
- **유선=켜짐**: VIN 인가되면 BQ25180이 ship에서 깨어나 SYS 출력 → 보드 기동.
- **버튼 3초=켜짐**: 푸시버튼 길게 → BQ25180 콜드스타트/웨이크 → SYS 래치.
- **소프트웨어 종료**: RP2040이 I2C로 **ship 모드 레지스터** 세트 → BQ25180이 BAT→SYS 차단(초저전류 nA~µA). 버튼/USB로만 재기동.

## 3. VSYS → 3V3 벅부스트 — **RT6150**

Pico/Pico W와 동일한 **벅부스트 컨버터**로 VSYS(1.8~5.5V)에서 안정적 3.3V 생성.
배터리가 3.3V보다 높든(만충 4.2V) 낮든(방전 3.0V) 항상 3.3V 출력 → 리포에 최적.

| 신호 | 연결 |
|---|---|
| VIN | VSYS (=BQ25180 SYS) |
| VOUT | **3V3 레일** (36핀 + RP2040/플래시/CYW43 전원) |
| EN | **3V3_EN(37핀)** — 풀업(예 100kΩ)→VSYS로 기본 ON |
| PS (파워세이브 모드) | **WL_GPIO1**(Pico W) 또는 GPIO23 — 저부하 효율 제어 |
| L (인덕터) | 2.2µH (데이터시트 권장) |
| 입출력 캡 | VIN 10µF, VOUT 22µF급 (데이터시트) |

- 3V3_EN(37핀)을 끌어내리면 보드 3.3V OFF(슬립과 별개의 하드 컷). 기본은 풀업으로 ON.

---

## 4. 배터리 커넥터

- **JST PH 2핀** (또는 SH 2핀, 공간에 맞게). BAT+ → BQ25180 BAT, BAT- → GND.
- 1셀 리튬폴리머(공칭 3.7V, 만충 4.2V). **보호회로(PCM) 내장 셀 권장.**
- 역삽 방지 표기. 커넥터는 USB측 확장영역에 배치(docs/07).

---

## 5. 전원부 핵심 주의 (요약)
1. **CC 5.1kΩ ×2 따로**, D± 양 페어 묶기 — USB-C 3대 실수 회피.
2. **충전 IC SYS → VSYS(39)**, Pico **VBUS핀 직결/역류 금지.**
3. 충전부는 **IC로만** — 직접 CC/CV 금지(발화).
4. 3V3는 **벅부스트로** 생성(LDO 아님) — 배터리 전 구간 커버.
5. 외부 USB-C와 다른 USB **동시 사용 금지.**
6. 모든 IC 핀번호·레지스터는 **데이터시트로 확정 후 작도.**
